◆ 数据库比对工具
数据源管理 比对任务 同步任务 比对报告 数据浏览 参数设置 退出

参数设置

全局默认值，新建同步/比对任务时自动带入；单个任务仍可在确认页覆盖。

默认同步模式

新建任务自动带入；确认页仍可改。推荐优先使用类 Navicat 的「数据传输 / 数据同步」。

差异同步

按主键比对：新增 INSERT、变更 UPDATE、目标多余 DELETE。

增量同步

不清空；主键存在则 UPDATE，否则 INSERT（不删多余行）。

数据传输

清空目标表后全量写入。

DML 全量

分批 DELETE 后批量 INSERT。仅需 DML。

DDL 全量

CREATE LIKE / TRUNCATE 路径，需 DDL 权限。

仅插入

不清空；INSERT IGNORE，冲突跳过。

DataX 工具同步

调用本机官方 DataX；大表推荐。需配置安装目录。

DataX（可选）

选择「DataX 工具同步」时必填。目录内应有 bin/datax.py（解压常为 ...\datax\datax 嵌套一层）。详见 scripts/datax/README.md。

「DataX DELETE/TRUNCATE」在 DataX 进程内执行清表，再写入；应用侧分批 DELETE 仅作兼容。
大表无 TRUNCATE、DELETE 又太慢时：清表选「不清空」+ 写入选 replace。
