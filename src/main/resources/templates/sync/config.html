增量同步

数据传输（类 Navicat）

DML 全量（默认）

分批 DELETE 后批量 INSERT。仅需 DML。

DDL 全量

CREATE LIKE / TRUNCATE，需 DDL 权限。

仅插入

不清空；INSERT IGNORE，冲突跳过。
